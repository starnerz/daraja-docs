This is the documentation site for the open source package
[`starnerz/laravel-daraja`](https://packagist.org/packages/starnerz/laravel-daraja).
It has no accounts, no sign-up, no comments and no forms. It is a set of static
pages.

This policy covers the documentation site only. It does not cover the package
itself, which runs on your own servers and sends data only to Safaricom, nor
Safaricom's Daraja APIs, which are governed by
[Safaricom's own privacy policy](https://www.safaricom.co.ke/privacy-policy).

## What is collected

<AnalyticsPolicy />

The site is hosted on GitHub Pages. GitHub records the usual web server
information for every request — IP address, user agent and the page requested —
and uses it to serve the site and to protect it from abuse. See
[GitHub's Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

## What is never collected

- No account, name, email address or payment information, because there is
  nowhere on this site to enter any.
- No advertising, ad networks, remarketing tags or cross-site trackers.
- No session recording, heatmaps or scroll tracking.

## Content loaded from elsewhere

Pages link out to GitHub, Packagist and Safaricom. Following a link means that
site sees the request and applies its own policy. Nothing on these pages is
embedded from a third party, so no third party is contacted until you click.

## Your rights

Kenya's Data Protection Act, 2019 gives you the right to be told what personal
data is held about you, to have it corrected or erased, and to object to its
processing. The equivalent GDPR rights apply if you are in the EU or UK.

Because this site collects no personal data itself, there is normally nothing
to access, correct or erase. For anything that reaches the maintainer — an
email, a GitHub issue — write to **stanleykimathi@gmail.com** and it will be
dealt with within thirty days.

If you believe your data has been mishandled, you may complain to the
[Office of the Data Protection Commissioner](https://www.odpc.go.ke) in Kenya,
or to your local supervisory authority.
